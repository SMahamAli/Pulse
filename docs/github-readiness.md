## What the demo can show

Register a fictional patient, select a hospital, review/submit intake, switch to staff in the same browser, confirm arrival, assign an available band and generate simulated readings from Devices. Switch back to report symptoms or request assistance; staff can review, reply, acknowledge alerts, record notes/decisions and confirm a destination. Closing the visit releases the band. Admin can create and activate/deactivate demo profiles.

Band assignment now waits for the first simulated reading. Freshness can expire, and disconnected devices retain their old readings. All connection states describe demo evidence, not a physical connection. The 15-minute stale label is a demonstration setting. Refresh the page to obtain updated server data; no automatic polling is configured. Waiting duration freezes when a visit closes.

General/help message review does not review a structured symptom update. Staff review each symptom in patient details; the model assessment remains pending until an actual result is supplied. Original intake is retained.
