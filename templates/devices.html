The access-check button requests no health data. The readings preview refreshes every 10 seconds and displays each sample's measurement time, age and daily statistics. Garmin Connect sync may be delayed.

Garmin setup instructions
  1. The owner should revoke any key shared in screenshots/chat and create a replacement in Garmin Connect.
  2. In this project folder, create .secrets/garmin-personal-api-key and put only the replacement key inside, on one line. This folder is ignored by Git. Never put it in templates, screenshots or chat.
  3. Alternatively configure the server environment variable GARMIN_PERSONAL_API_KEY. An existing environment variable takes priority over the file.
  4. Click Check Garmin API access. Python sends the credential only to Garmin's official token endpoint. The returned token is discarded, not shown or stored.

No vendor passwords are collected. A personal key is for its owner's data, not every patient's Garmin. This check is not a multi-user Garmin authorisation flow.
